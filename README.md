## Selected work

| | | |
|---|---|---|
| **[Dhristi](https://github.com/varundevarajrvu/sih)** | A browser agent that *sees* the page without leaking it — object detection runs on-device via WebGPU, PII is redacted before anything leaves the client. | `in progress` |
| **[Nyxa](https://github.com/varundevarajrvu/nyxa)** | Voice + hand-gesture assistant for Windows that runs entirely on-device — wake word to action, zero cloud, zero API keys. | `shipped` |
| **[Skryver](https://github.com/varundevarajrvu/skryver)** | Offline voice dictation for Windows — local STT (sherpa-onnx) + local LLM cleanup (llama.cpp), nothing ever leaves the machine. | `shipped` |
| **[tiny-gpt](https://github.com/varundevarajrvu/tiny-gpt)** | A GPT-style language model built from scratch and trained CPU-only on a laptop — byte-level BPE, resumable training loop. | `research` |
| **[MoodSync](https://github.com/varundevarajrvu/moodsync)** | A camera reads the room's mood, the room responds — on-device FER+/ONNX inference driving real RGB hardware over serial. | `prototype` |
| **[ResuRate](https://github.com/varundevarajrvu/resurate)** | A resume rewrite engine with a signed anti-fabrication claims gate — the rubric score is capped by the weakest category, not averaged. | `v0` |
